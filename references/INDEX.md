# Reference Library — Catalog

An ongoing archive of design references. Files live in `references/library/`;
this file is the searchable index. Every reference fed into any run of the
workflow gets archived here and can be reused by every future run.

## How entries work

- **ID**: `ref-NNN`, sequential, never reused. Filename is
  `library/ref-NNN-<short-slug>.<ext>`.
- **Tags**: lowercase style adjectives + subject type, comma-separated —
  these are what future Stage-1 searches match against (e.g. `neon, noir,
  dark, glass, link-in-bio`).
- **Source**: where it came from (URL, "user upload", styles.refero.design
  page, getdesign.md name).
- **Used by**: which creator projects have used it (append, don't replace).
- **Verdict**: after a project ships, note whether the direction it inspired
  won or lost — losses are as useful as wins for steering future picks.
